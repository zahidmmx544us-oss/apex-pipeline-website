Available REST API Endpoints

GET
/api/posts
Retrieve list of posts (supports ?search=, ?category=)
POST
/api/posts
Create a new blog post with JSON body (title, content, category, etc.)
GET
/api/posts/:id
Retrieve a single blog post by its unique ID
PUT
/api/posts/:id
Update an existing blog post
DELETE
/api/posts/:id
Permanently remove post from database
POST
/api/posts/:id/like
Increment like counter for an article
POST
/api/posts/:id/comments
Add reader comment to article
GET
/api/status
Server health, MongoDB status, and uptime

Backend Architecture Flow

1
Browser / Client: Sends HTTP request via fetch('/api/posts')
2
Express Router: Routes request to matching controller (postController.js)
3
Mongoose Model: Validates schema and performs MongoDB queries (Post.find())
4
MongoDB Database: Stores document data in collections permanently
